# 智能线耗计算器

服装生产用线量（线耗）计算工具：导入 DXF 纸样 → 智能识别工艺部位 → 左右对比参考历史工序 → 计算单件线耗、缩率补偿、损耗余量、订单总用线与线卷采购量。

## 使用方式

1. **免安装 EXE（推荐）**：在 [Releases](https://github.com/Jaylorandy/thread-consumption-calculator/releases/latest) 下载 `线耗计算器.exe`，双击运行，无需安装 Python 或浏览器。
2. **网页版**：<https://jaylorandy.github.io/thread-consumption-calculator/>

## 版本更新

- 每次打开软件自动检测 GitHub 最新版本，发现新版本弹窗提示，可直接下载新版 EXE。
- 页面右上角「检查更新」按钮可随时手动检测。
- 选择「跳过此版本」后该版本不再自动提示（手动检查仍会提示）。

## 主要功能

- DXF 解析：支持 POLYLINE / LWPOLYLINE / ARC 与凸度弧段，按真实弧长计算
- **缝段归并**：CAD 导出的轮廓会被离散成大量短边，系统按方向归并还原成真实缝段（侧缝/内缝取归并后长度，而非最长单条边）
- 工艺部位生成：侧缝 / 内缝 / 前浪 / 后浪 / 腰头 / 袋位等，公共边只计一次
- 线迹库：101 / 301 / 304 / 401 / 406 / 503 / 504 / 514 / 516 / 602 / 605 及锁眼、钉扣、套结等点位工序
- Coats 标准线耗比对照列（仅参考，不参与计算）
- 参数：面料厚度档、面料缩率、损耗率、缝份扣减、工艺附加、订单数量、线卷长度
- 历史款式库、工序模板、系数管理、数据备份与恢复、CSV 明细导出、AI 训练用 JSON 导出

## 参数说明

| 参数 | 说明 | 默认 |
|---|---|---|
| 面料厚度档 | 影响耗线系数（薄/中厚/厚） | 中厚 |
| 损耗率 % | 线头、断线、换梭等 | 8 |
| 面料缩率 % | 水洗/热缩补偿 | 5 |
| 缝份扣减 cm | DXF 导出的是毛线（含缝份），车缝走净线，每片边扣一次缝份 | 1.0 |
| 工艺附加 % | 里布、双股线、装饰线等未单独建模的工序 | 25 |
| 订单数量 / 线卷长度 | 采购量换算 | 1000 / 5000m |

## AI 校准（v2.3.0 新增，v2.3.1 修复连接）

接入智谱 GLM API，用 AI 做**工艺语义判断与异常诊断**——例如"内缝 57cm 短于侧缝 92cm 是否合理"、"这批数据有没有漏工序"。

**关于连接方式（重要）**

智谱 API **不允许浏览器跨域直连**（其预检响应不含 `Access-Control-Allow-*` 头），纯前端 `fetch` 必然报 `Failed to fetch`。因此：

- **桌面版 EXE**：内置本机代理（`launcher.py` 的 `/api/glm/chat`），由 Python 转发，浏览器只与 `127.0.0.1` 通信，同源无跨域问题，**开箱即用**
- **网页版（GitHub Pages）**：无本机代理，需自建反向代理中转，或改用桌面版
- 代理仅允许转发到智谱官方端点；API Key 通过 `X-GLM-Key` 头随请求传递，服务端不落盘

**职责边界（重要）**
- 几何计算（弧长、轮廓周长、缝段归并）始终由本地代码完成，AI 不参与
- AI 只判断"这个缝长是否符合该部位的工艺常识"
- AI 给出的数值修正**必须逐条确认后**才生效，且只作用于匹配到的工序

**工艺基准库（v2.4.0 新增）**
- 内置 26 条部位缝长参考区间（裤装 14 / 上衣 10 / 裙装 2），数据来源为软件内置的 4 款历史款式实测
- 每道工序自动匹配对应部位区间，AI 校准时一并提供，能给出**具体建议值**而不是"比例不匹配"这类空话
- 区间数据可按自身工厂工艺调整（改 `PART_BENCHMARK` 常量）

**历史款式参照**
- 校准时自动附上同类历史款式的实测用线量与理论值对比，用于总量校验
- 内置 4 款：784LK 外套 355.43m / 0503 长裤 277.59m / 0019 夹克 472.15m / 0056 短裤 224.19m
- 用户自存款式同样纳入参照

**踩坑经验库**
- 按「品类」×「问题类型」双维度组织，避免只按品类导致跨品类经验重复漂移
- 每次校准只检索并注入相关条目（通常 ≤12 条），控制上下文与成本
- 新经验与已有结论冲突时会提示人工裁决，不自动覆盖
- 置信度随采纳/否决自动升降，90 天未命中的条目降权
- 支持 JSON 导入导出，便于团队共享经验

**API Key**
- 在「AI 校准」面板中填入你自己的智谱开放平台 Key
- Key 仅保存在本机浏览器存储（localStorage），不写入程序、不随分发泄露
- 建议在 https://bigmodel.cn 控制台申请；日常用 `GLM-4-Flash`（免费），复杂问题用 `GLM-4.6`
- 点「环境自检」可查看当前连接通道、模块加载、按钮绑定、Key 状态等完整信息

## 数据说明

所有数据保存在本机浏览器 localStorage 中，不上传服务器。更换电脑或清理浏览器数据前，请用「备份数据」导出 JSON 备份。
